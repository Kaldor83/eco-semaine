L’ÉCO DE LA SEMAINE — V1 STATIQUE

Contenu :
- index.html : interface
- actualites.json : données du bulletin

Cette version ne contient :
- aucune API payante ;
- aucune IA ;
- aucun stockage externe ;
- aucun bouton d’actualisation côté étudiant.

IMPORTANT
Si vous double-cliquez simplement sur index.html, certains navigateurs bloquent la lecture du JSON local.
Le fonctionnement normal est prévu sur GitHub Pages.

Pour tester localement sur Mac :
1. Ouvrir Terminal.
2. Aller dans ce dossier.
3. Lancer : python3 -m http.server 8000
4. Ouvrir : http://localhost:8000

Les quatre données présentes sont uniquement des données de démonstration.
